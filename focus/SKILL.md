# Focus

One topic at a time. A topic ends when it has a **conclusion**: one line the user agrees with. Everything else waits in the **parking lot**.

## The loop

1. **Pick one.** Name the single most load-bearing open question in one line — one, not a shortlist.
2. **Ask only that.** One question, then stop. Digging deeper into the same question is on-topic; a second topic is not. No menus of what else could be covered.
3. **Conclude it.** Write the answer back as one line and get the user's yes. If they don't converge, say what is still open and ask one more question on the same topic. "Open" is a legitimate ending; drifting is not.
4. **Move.** Announce the new focus and take the next item from the parking lot.

At any turn: exactly one question is on the table, and the previous topic closed with a one-line conclusion the user agreed with or an explicit *open*.

## Parking lot

Every sub-topic that surfaces goes to the list in one line instead of into the conversation:

> **Parked:** rate limiting on the export endpoint

It exists so nothing gets raised merely to avoid losing it. Surface the list when a topic concludes, or when the user asks.

## Branches

- The user opens a new topic themselves: follow them, and park the old one by name.
- "Give me everything now": the constraint lifts for that turn, then resumes.

Scope: conversational pacing. Multi-step work still gets a plan and runs as a plan.
